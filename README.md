# AI Browser Agent — 설치 파일 다운로드

말로 명령하면 AI가 내 PC의 실제 Chrome/Edge를 열어 검색·클릭·입력·자료 수집을 하는 Windows 데스크톱 앱입니다.
본인의 OpenAI 또는 Gemini API 키로 동작합니다(BYOK). 이 저장소에는 **설치 파일만** 올립니다.

- **바로 다운로드 (최신 버전):** https://github.com/baenamedu-bot/ai-browser-agent-download/releases/latest/download/AI-Browser-Agent-Setup.exe
- 소개 페이지: https://ai-browser-auto.vercel.app
- 지원: Windows 10/11 (64비트)

## 설치
1. `AI-Browser-Agent-Setup.exe` 를 실행합니다.
2. 코드 서명 전이라 파란 경고창(SmartScreen)이 뜨면 **추가 정보 → 실행**을 누르세요.
3. 첫 실행 설정에서 AI(OpenAI/Gemini) 선택 → API 키 입력 → 연결 테스트 → 저장.

로그인·결제·최종 제출은 AI가 대신하지 않고 사용자 확인을 요청합니다. 1차 테스트 버전입니다.
